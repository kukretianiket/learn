# Learning

Use Codex and Obsidian side by side. Start a lesson in Codex with `$learn`; the live session appears in [[Sessions]], durable topic models in [[Topics]], and verified references in [[Sources]].

## Review

Open [[Review Queue.base]] when Obsidian Bases is enabled, or run:

```bash
python3 ~/.agents/skills/learn/scripts/learnctl.py due
```

## Folders

- [[Sessions]] — live lesson transcripts and syntheses
- [[Topics]] — evidence-based mental models and retrieval prompts
- [[Sources]] — provenance for sources actually used
- [[Assets]] — generated local SVG/PNG visuals
